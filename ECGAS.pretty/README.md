# Project footprints

Both custom footprints are now supplied. See ../PCB_README.md for source drawings and assembly requirements.

- ADuCM355_LGA-72_6x5mm: CC-72-2 top-view pin grid, 72 lands, 0.5 mm pitch, 6 x 5 mm body, 0.25 mm copper pads, 0.025 mm mask expansion.
- EC_Sense_ES1_3pin_2.54mm: 3 x Mill-Max 0548-0-15-15-21-27-10-0, finished 1.0 mm PTH. C/S/R numbering follows the schematic, mirrored correctly from the sensor bottom view. Courtyard conservatively accommodates the undimensioned pin-row offset.

Standard KiCad footprints used by this project are vendored under ../libraries/. 3D socket bodies are illustrative and do not replace manufacturer drawings.
